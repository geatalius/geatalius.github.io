# 폰 리모컨 📱→💻

안드로이드 휴대폰으로 노트북을 원격 제어하는 프로그램입니다.
노트북에서 작은 서버를 실행하고, 휴대폰은 **크롬 브라우저로 접속만 하면** 됩니다 (앱 설치 불필요).

## 기능

- **노트북 화면 실시간 보기** (화질·해상도·FPS 조절, 여러 모니터 선택)
- **터치패드 모드** – 한 손가락: 마우스 이동 / 탭: 왼쪽 클릭 / 두 손가락 탭: 오른쪽 클릭 /
  세 손가락 탭: 가운데 클릭 / 두 손가락 끌기: 스크롤 / 두 번 탭 후 끌기: 드래그
- **직접 터치 모드** – 폰 화면에 보이는 노트북 화면을 누른 위치를 바로 클릭, 길게 누르면 오른쪽 클릭, 끌면 드래그
- **키보드** – 입력창에 쓰는 대로 노트북에 실시간 타이핑 (한글 가능), Esc/Tab/방향키/Ctrl·Alt·Shift·Win 조합
- **단축키** – 복사, 붙여넣기, 실행취소, 창 전환(Alt+Tab), 바탕화면, 화면 잠금 등
- **미디어** – 볼륨 조절, 음소거, 재생/정지, 이전/다음 곡
- 전체화면 + 가로 모드, 연결이 끊기면 자동 재연결

## 설치 & 실행

1. 노트북에 [Python 3.9 이상](https://www.python.org/downloads/)을 설치합니다.
   (Windows: 설치 화면에서 **"Add python.exe to PATH"** 체크)
2. 이 `remote-control` 폴더를 노트북에 받습니다.
3. 실행
   - **Windows**: `start-windows.bat` 더블클릭
   - **macOS / Linux**: 터미널에서 `./start-mac-linux.sh`
   - (직접 실행) `pip install -r requirements.txt` 후 `python server.py`

   처음 실행할 때는 필요한 패키지를 자동으로 설치합니다.
4. 창에 **주소, 접속 코드, QR 코드**가 나옵니다.
5. 휴대폰을 노트북과 **같은 Wi-Fi**에 연결하고, QR 코드를 카메라로 찍거나 주소를 크롬에 입력합니다.
6. 크롬 메뉴 → **"홈 화면에 추가"** 하면 앱처럼 쓸 수 있습니다.

> Windows에서 처음 실행하면 방화벽 허용 창이 뜹니다. **"개인 네트워크"에 허용**을 눌러야 폰에서 접속됩니다.

### 옵션

```
python server.py --port 9000        # 포트 변경 (기본 8765)
python server.py --code mysecret    # 접속 코드를 고정 (기본: 실행할 때마다 새로 생성)
```

접속 코드를 고정하면 홈 화면에 추가한 바로가기로 매번 바로 연결됩니다.

## 운영체제별 참고

| OS | 참고 |
|---|---|
| Windows 10/11 | 바로 동작합니다. 관리자 권한으로 실행된 프로그램(작업 관리자 등)을 조작하려면 서버도 관리자 권한으로 실행해야 합니다. |
| macOS | 시스템 설정 → 개인정보 보호 및 보안에서 터미널(또는 Python)에 **손쉬운 사용**과 **화면 기록** 권한을 줘야 합니다. |
| Linux | **X11 세션**에서 동작합니다. Wayland에서는 화면 캡처와 입력 제어가 막혀 있으니 로그인 화면에서 "Xorg" 세션을 고르세요. |

## 보안

- 접속 코드가 있어야만 제어할 수 있고, 코드는 실행할 때마다 새로 만들어집니다.
- 통신은 암호화되지 않은 HTTP이므로 **집처럼 믿을 수 있는 Wi-Fi에서만** 사용하세요.
  공유기에서 포트 포워딩해서 인터넷에 공개하지 마세요.
- 사용이 끝나면 서버 창에서 `Ctrl+C`로 종료하세요.

## 문제 해결

- **폰에서 접속이 안 돼요** → 같은 Wi-Fi인지, 방화벽에서 허용했는지 확인하세요.
  게스트 Wi-Fi는 기기끼리 통신을 막는 경우가 많습니다.
- **화면이 끊겨요** → 설정 탭에서 화질·해상도를 낮추거나, 화면 버튼을 꺼서 터치패드만 쓰세요.
- **클릭 위치가 어긋나요 (Windows)** → 최신 버전으로 실행했는지 확인하세요. 화면 배율(125%, 150%)을 자동 보정합니다.

## 파일 구성

```
remote-control/
├── server.py            # 노트북에서 실행하는 서버 (화면 캡처 + 마우스/키보드 제어)
├── static/index.html    # 휴대폰에서 열리는 리모컨 화면
├── requirements.txt
├── start-windows.bat
└── start-mac-linux.sh
```
